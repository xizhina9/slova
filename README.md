# Слова — личный тренажёр английской лексики

Приложение: `index.html` (открывается по адресу GitHub Pages этого репозитория).
Словарь: `words.json` — один объект на слово:

```json
{"id":"w0076","en":"word","pos":"noun","ru":"перевод","ex":"Example sentence.","topic":"build","level":"B2","tags":["AWL1"],"src":"откуда","added":"2026-09-27"}
```

`id` уникален и не меняется (`w` + 4 цифры, по порядку). Остальные поля кроме `en` и `ru` необязательны.

`topic` — одно из: `build` Архитектура и строительство · `acad` Академическая лексика · `sci` Наука и технологии · `edu` Образование · `soc` Общество и культура · `eco` Экология · `health` Здоровье · `work` Работа и бизнес · `city` Города и жильё · `travel` Путешествия · `talk` Разговорное.
`level` — `B1`, `B2` или `C1`. `tags` — свободные метки (например, `AWL1`…`AWL10` для подсписков Academic Word List).
Приложение подхватывает новые слова при следующем открытии — ничего пересобирать не нужно.

## Как пополнять (для Claude)

В новом чате пришли Claude слова в любом виде (Excel, фото словаря, текст) и напиши:

> Добавь эти слова в мой словарь. Репозиторий: `ЛОГИН/slova`, файл `words.json`. Токен: `...`

Claude распознаёт слова, вычищает дубли (по полю `en`), дописывает перевод и пример, если их нет,
проставляет `topic` и `level` и добавляет записи в конец `words.json` через GitHub API (скрипт `push.py`:
`GH_TOKEN=... python3 push.py "сообщение" words.json`).

## Цель и план

Владелец готовится к IELTS Academic (цель 7.5, старт B1–B2, сдача через ~6 месяцев).
Этапы развития приложения: 1) темы и паки слов ✔ 2) карточки ошибок из проверки эссе 3) Reading и Listening 4) Speaking и отчёт о прогрессе.

## Прогресс

Хранится в браузере телефона. Резервная копия — в настройках приложения («Скопировать копию» / «Восстановить»).
