# Слова — личный тренажёр английской лексики

Приложение: `index.html` (открывается по адресу GitHub Pages этого репозитория).
Словарь: `words.json` — один объект на слово:

```json
{"id":"w0076","en":"word","pos":"noun","ru":"перевод","ex":"Example sentence.","topic":"build","level":"B2","tags":["AWL1"],"src":"откуда","added":"2026-09-27"}
```

`id` уникален и не меняется (`w` + 4 цифры, по порядку). Остальные поля кроме `en` и `ru` необязательны.

`topic` — одно из: `build` Архитектура и строительство · `acad` Академическая лексика · `sci` Наука и технологии · `edu` Образование · `soc` Общество и культура · `eco` Экология · `health` Здоровье · `work` Работа и бизнес · `city` Города и жильё · `travel` Путешествия · `home` Дом, еда и быт · `nature` Природа и животные · `leisure` Хобби, спорт и досуг · `talk` Разговорное.
`level` — `B1`, `B2` или `C1`. `tags` — свободные метки (например, `AWL1`…`AWL10` для подсписков Academic Word List).
Приложение подхватывает новые слова при следующем открытии — ничего пересобирать не нужно.

## Как пополнять (для Claude)

В новом чате пришли Claude слова в любом виде (Excel, фото словаря, текст) и напиши:

> Добавь эти слова в мой словарь. Репозиторий: `ЛОГИН/slova`, файл `words.json`. Токен: `...`

Claude распознаёт слова, вычищает дубли (по полю `en`), дописывает перевод и пример, если их нет,
проставляет `topic` и `level` и добавляет записи в конец `words.json` через GitHub API (скрипт `push.py`:
`GH_TOKEN=... python3 push.py "сообщение" words.json`).

## Ученик и формат занятий

- Уровень: диагностика 16/30 → B1 (сильные зоны: артикли, предлоги, лексика блоками). Цель — IELTS Academic 7.5, сдача через ~6 месяцев. Профессия — архитектор (lead concept architect, Revit / BIM).
- Формат уроков в чате: объяснения по-русски, практика по-английски; тема → короткая теория → 8 упражнений → мини-продакшн (2–4 своих предложения). Разбор: похвала → чистая версия в цитате → поправки с «почему». Ученик любит пропускать продакшн — мягко настаивать.
- Сигналы: «газ» / «газ дальше» — продолжай; «Делай. Ты командир» — веди сам. Тон тёплый, энергичный.
- Следить в речи: **actual** (ложный друг, ×3), **i → I**, выбор времени и залога (съезжает в перфект и пассив), **опечатки**, on time / in time, существительное-определение в ед. ч., артикли с конкретным.
- Каждую новую ошибку из эссе и надиктовок добавлять в набор `err-stop` (тип `fix`, фраза ученика с одной ошибкой).

- При добавлении нового слова по запросу ученика заводить отдельными карточками 1–4 самых ходовых и базовых синонима (если их ещё нет в словаре), в note слова перечислять синонимы.

## Где что лежит

- `words.json` делится только по темам (`topic`) и уровням (`level`), источник слова в интерфейсе не показывается. Теги (`tags`) — только тематические: разделы темы `build` (АР, ГП, Конструктив, Материалы, ОВ, ВК, Электрика, Организация) и подсписки `AWL1`… Academic Word List. Откуда слово — только в поле `src`. Перед добавлением сверять с существующими словами по паре (en, topic): омонимы с другой темой — отдельные карточки; ошибки и опечатки источника молча исправлять, в note их не упоминать (note — только о самом слове). Ошибки ученика появляются только из заданий, эссе и надиктовок и идут в `err-stop`.
- `exercises.json`: «Мои ошибки» (стоп-лист, ложные друзья) · «Грамматика» (Блок 1 уроков + доп. наборы) · «Лексика в контексте» (Блок 2 уроков) · «IELTS» (каркасы Speaking Part 2) · «Замер прогресса» (диагностика, `mode: "test"`, без интервальных повторов, с baseline и разбивкой по `sec`).
- Поле `note` у слова — пометка (UK/US, произношение, ловушка), показывается после ответа. У задания: `cs: true` — проверка с учётом регистра; `t` или `fixTask` у набора — свой текст задачи для `fix`.

## Чтение

- `reader.html` — читалка внутри приложения, вход с главной «Слов» (раздел «Чтение»), назад — «‹ Слова». Открывать её нужно из приложения: у ярлыка на экране «Домой» своё хранилище, и слова из отдельного ярлыка до тренажёра не дойдут.
- Книги — `books/*.json` (сейчас The Mysterious Island, Jules Verne, английский перевод 1875 г., общественное достояние). Формат: `{title, author, lang, chapters: [{t, g, n, b}]}`, `t` — глава, `g` — часть, `n` — число слов, `b` — абзацы-строки и заголовки `{h, l}`. Встроенные книги перечислены в `BUNDLED` в `reader.html`. Свои EPUB/FB2/TXT ученик открывает с устройства: они хранятся в IndexedDB браузера, в репозиторий не попадают.
- Перевод по касанию — онлайн: словарь Google Translate по частям речи и английское определение (неофициальный бесплатный адрес `translate.googleapis.com/translate_a/single?client=gtx`, может перестать отвечать), запасной — MyMemory; транскрипция — dictionaryapi.dev. Если после слова стоит частица (out, up, off…), отдельно предлагается фразовый глагол. «Спросить Claude» открывает чат с вопросом о слове в контексте.
- Разбор трудных слов (готовое объяснение без интернета, онлайн-словарь — для остальных): `books/gloss/<книга>/NN.txt`, файл на главу, строка `формы|лемма|часть речи|перевод в этом месте|уровень|пометка|заметка`. Формы — как в тексте, в нижнем регистре, через `/`; часть речи — n, v, adj, adv, prep, pv, id, ph; пометка `+` стоит учить, `-` можно не учить, `*` значение только для этой главы. `python3 gloss.py mysterious-island` собирает `books/mysterious-island.gloss.json` и проверяет, что каждая форма есть в тексте. Уже разобранное в прошлых главах не повторять: читалка находит слово по всей книге (кроме `*`) и узнаёт простые формы (-s, -ed, -ing, -ly). Готовы главы 1–5 первой части; следующие делать порциями по просьбе ученика, экономно: только B2+ и непривычные значения, фразовые глаголы, идиомы, устаревшее с пометкой `-`.
- Сохранённые слова — localStorage `rdr.words`: `{slug: {en, pos, ru, ex, ipa, book, ch, added}}`. Тренажёр подмешивает их как тему `read` («Из книг», id `r-<slug>`, `src`: «книга: …»); если такое `en` уже есть в `words.json`, копия из книги не показывается. Резервная копия в настройках их включает. Позиция чтения — `rdr.pos.<id>`, для главной — `rdr.now`.
- Чтобы перенести слова из книги в общий словарь с синонимами, ученик присылает список («Мои слова» → «Скопировать список для Claude»); карточки оформлять по правилам выше.
- Есть и отдельная версия читалки в Claude (перевод с учётом контекста делает сам Claude): https://claude.ai/artifact/YbBauS1pqyRg2LsQBbVvZM. Слова оттуда лежат в базе артефакта, коллекция `words` (ArtifactData), поле `synced`.
- Доступ к репозиторию в текущем аккаунте Claude — через GitHub-коннектор: токен не нужен, изменения отправляются обычным `git push`.

## Порядок занятий (рекомендация ученику)

Каждый день ~35 минут: стоп-лист → слова (паки по уровню B1 → B2 → C1, через день «Архитектура и строительство»; режимы Карточки → Выбор → Письмо) → один набор грамматики по номеру 1–14 (переходить дальше, когда ошибок почти нет). 2–3 раза в неделю: «Лексика в контексте», «Ложные друзья», IELTS-наборы (связки, Speaking Part 2 с надиктовкой в чат). Диагностика — раз в 3–4 недели (следующая — вторая половина октября 2026). Параллельно — Writing Task 2 в чате.
Следующие порции словаря: язык Writing Task 1 (тренды, сравнения), затем AWL 4–10.

## Цель и план

Этапы развития приложения: 1) темы и паки слов ✔ 2) стоп-лист ошибок ✔, проверка эссе и надиктовок с пополнением стоп-листа 3) Reading и Listening 4) Speaking и отчёт о прогрессе.
Следующее в уроках: мини-блоки по 5–7 проф. терминов с предложением о проекте «Monaco» → Блок 3 IELTS Writing, Task 2 (эссе-мнение 150–200 слов).
Не пройдено (C1, позже): инверсии (No sooner… than, Had I known…), смешанные условные.
